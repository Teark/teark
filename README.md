# 与道对话

在星空下，与跨越时代的思想者展开一场对话。

这里收录了 1000 位历史、哲学、宗教与神话人物，其中中国人物 600 位、其他地区人物 400 位。你可以向孔子询问修身，和苏轼聊人生，也可以与三国谋士贾诩探讨进退与抉择。

## 你可以做什么

- **浏览人物相册**：环形相册每次打开时随机排列。点击头像或左右箭头切换，也支持相册区域滚轮、滑动及非输入状态下的左右方向键。
- **切换浏览模式**：相册右下角开关可选择“顺序切换”或“随机切换”。顺序模式沿当前相册逐张切换；随机模式每次切换到另一位人物。模式保存在当前浏览器，点击头像和指定人物搜索仍能直接选择对应人物。
- **指定对话人物**：点击左侧“指定对话”输入框，按影响力参考分数浏览姓名；输入姓名可实时筛选。点击候选人物，或用上下方向键选中后按 Enter，即可切换。找不到的人物无法直接选择；Esc 可收起列表。排序分数是本地估算，综合热度、贡献与思想影响，并非实时热度或权威历史排名。
- **向人物提问**：在底部写下问题，点击发送或按 Enter；Shift + Enter 换行。回答由 AI 根据人物的思想风格与背景生成。
- **继续历史对话**：左侧保存对话记录，支持搜索。点击记录可返回对应人物及会话；切换人物时会优先恢复其已有对话。
- **开启新的讨论**：点击“新建对话”，为当前人物创建一个独立会话。
- **导出完整长图**：点击输入框内部右上角的导出图标，将当前会话保存为一张 PNG 长图。顶部是人物相册，下方包含全部消息，背景为星空；相册收起或消息滚动都不会截断内容。没有对话或正在生成回答时不可导出。导出在本地完成，不上传对话内容。
- **管理人物**：通过“人物管理”搜索、添加或移除人物。新增人物会自动补充介绍、时代和代表语录，并提供示意头像。
- **收起侧栏**：点击标题旁的箭头，为相册和对话留出更多空间。
- **收起相册**：点击相册右下角的收起图标，相册及顺序/随机开关一起向上收起，为对话腾出空间。点击展开图标即可恢复；每次打开页面默认展开。

## 开始使用

1. 打开网站，在相册或“指定对话”中选择人物。
2. 点击左下角设置按钮，填写自己的 DeepSeek API Key 并保存。
3. 输入问题，开始对话。无需密钥也可以浏览人物和已有示例会话；生成新回答需要有效密钥和网络连接。

你可以从这些问题开始：

- “面对不确定的未来，我应该如何选择？”
- “你最重要的思想，今天还能怎样帮助我们？”
- “如果你面对我的处境，会如何判断进退？”

## 对话、隐私与人物形象

对话记录、人物管理修改和 API Key 保存在当前浏览器本地，不会自动在不同设备或浏览器间同步。清除网站数据可能导致记录和设置丢失。请勿在公共电脑保存密钥。

生成回答时，相关对话内容会发送给 DeepSeek 服务。API 调用是否收费、密钥是否可用，以你的服务账户为准。

人物回答是 AI 模拟，不是历史人物的真实发言，也不保证所有史实或引文准确。适合交流与启发；严肃研究请核对原始文献。

所有内置人物均有本地头像，包含历史肖像、传统绘像、雕像照片、后世插画和人物组合图。少数人物使用明确标注的“原创示意”插画；这些形象不代表真实容貌。图片加载失败时也会回退到示意插画。网络图片来源与许可状态有记录，但部分许可尚未核实，不能据此认定可自由用于商业用途。

## 在自己的电脑上运行

安装 Node.js 与 npm 后，在项目目录执行：

```sh
npm install
npm run dev
```

打开终端显示的本地地址即可使用。

如需生成可部署的网站文件：

```sh
npm run build
npm run preview
```

构建文件位于 `dist/`，包含实际使用的头像资源；AI 对话仍需网络连接。浏览器本地保存的数据不会随网站文件一起打包。

## 图片维护

人物头像统一使用 192×192 WebP，质量参数为 65；银河背景长边不超过 960 像素。更新头像后运行 `npm run assets:optimize` 和 `npm run portraits:verify`。已经符合尺寸的头像会跳过压缩，避免反复损失画质。图片来源、作者及许可记录保留在 `src/portraitCredits.js`。

历史图片采集记录、一次性下载和修复脚本已清理。`dist/` 与 `node_modules/` 为可重新生成的本地目录，不提交到 Git。
